ot-core

Operational Transform for plain text, with the convergence property actually tested. Zero dependencies, ESM, about 30 kB.

Open the playground Source on GitHub npm

I wrote an OT implementation, load-tested it to 1,000 concurrent clients, and shipped it. Then I property-tested the one law it exists to uphold and 16.2% of concurrent edit pairs diverged. This is that implementation with the bugs found and fixed — and the test suite is the point of it.

The playground is three real clients and a real server over a network you can break on purpose. Its second mode takes the server away, which is enough to make the same three edits land on two different documents.
